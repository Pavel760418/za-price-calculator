# Отчёт для руководителя
## Эволюция модуля ценообразования «Зеленое Яблоко»: от Excel к веб-приложению

**Проект:** ZA Price Calculator  
**Сеть:** супермаркеты «Зеленое Яблоко»  
**Репозиторий:** https://github.com/Pavel760418/za-price-calculator  
**Текущее состояние:** Релиз 3.5 (актуально на август 2026)  
**Назначение документа:** краткое описание пути развития продукта и результатов трёх релизов

---

## 1. Исходная точка: ручной Excel-калькулятор

До автоматизации коммерческий блок работал с локальными Excel-файлами (`ZY_price_calculator.xlsx`, `ZY_price_calculator_v2.xlsx`, эталонный `ZA_Price_Calculator.xlsx`).

В этих файлах уже была заложена бизнес-логика:
- сравнение розничных цен ЗЯ с ценами конкурентов;
- расчёт наценки и маржи от закупочной цены;
- несколько сценариев ценообразования;
- KPI и сигналы риска.

**Ограничения исходного подхода:**
- файл нужно было копировать и заполнять вручную;
- высокий риск поломки формул при правках «на месте»;
- сложно масштабировать на новые прайс-листы;
- нет единого веб-доступа для команды;
- нет автоматических выводов «что делать с ценами».

Именно эта Excel-логика стала фундаментом всех последующих релизов: математика не придумывалась заново, а переносилась в код с сохранением совместимости итогового файла.

---

## 2. Логика эволюции продукта

Путь развития можно описать в трёх шагах:

1. **Автоматизировать Excel** — чтобы прайс загружался, а готовая книга с формулами собиралась программно.  
2. **Дать доступ через браузер** — чтобы коммерческий блок не ставил Python и не запускал скрипты.  
3. **Упростить работу с ценами** — оставить на виду только нужные сценарии и добавить удобный ручной ввод новой розничной цены с мгновенным пересчётом наценки.

Ниже — содержание каждого релиза.

---

## 3. Первый релиз — Python-модуль и базовая веб-обёртка

**Цель:** перенести эталонный Excel-калькулятор в устойчивый программный модуль и дать простой способ запуска через браузер.

### Что сделано

**Ядро на Python (`za_price_calculator`):**
- чтение прайс-листа и (опционально) файла продаж;
- нормализация колонок и синонимов заголовков;
- автоматическая сборка книги из 6 листов:
  1. Инструкция  
  2. Исходные данные  
  3. Продажи  
  4. Расчеты  
  5. Dashboard  
  6. Сценарный анализ  
- сохранение формул, оформления и условного форматирования, близких к эталонному Excel;
- два способа запуска: программный API (`ZAPriceCalculator.run(...)`) и CLI.

**Базовое веб-приложение (Streamlit):**
- загрузка прайс-листа и файла продаж через браузер;
- формирование итогового Excel «в один клик»;
- кнопка скачивания готовой книги;
- подготовка к публикации на Streamlit Community Cloud.

### Результат для бизнеса

Вместо ручного копирования шаблона сотрудник загружает актуальный прайс и получает готовый калькулятор со всеми формулами. Логика стала воспроизводимой, ошибки ручного копирования формул снизились.

---

## 4. Второй релиз — AI-агент и BI-дашборд в браузере

**Цель:** превратить «просто генератор Excel» в рабочий инструмент принятия решений по ценам прямо в веб-интерфейсе.

### Что сделано

**Переработка веб-приложения:**
- полностью русский интерфейс;
- брендинг сети «Зеленое Яблоко» (AI-агент ценообразования);
- современный UI: KPI-карточки, вкладки, графики.

**Встроенный BI-дашборд (без обязательного открытия Excel):**
- ключевые показатели: средняя маржа, наценка, ВП/ед., доля позиций выше/ниже рынка;
- графики позиционирования по рынку и распределения маржи;
- сравнение сценариев ценообразования;
- автоматические выводы и рекомендации («что стоит пересмотреть»);
- топ позиций по марже и топ позиций выше рынка;
- параллельно — скачивание полной Excel-книги.

**Сопутствующие улучшения:**
- шаблон файла продаж и кнопка его скачивания;
- метка версии интерфейса (чтобы понимать, какая сборка сейчас на Cloud);
- устойчивость к «грязным» данным (например, пустые колонки конкурентов).

### Результат для бизнеса

Коммерческий блок получил не только файл «на потом», а мгновенную картину ассортимента: где цены завышены, где есть запас маржи, какие сценарии дают лучший баланс цены и прибыли. Excel остался рабочим артефактом, но первичный анализ стал доступен в браузере.

## 5. Третий релиз — управление новой ценой и упрощение сценариев

**Цель:** сделать инструмент удобнее для ежедневной работы ценообразования: быстро видеть текущую наценку, вручную задавать новую розничную цену и считать новую наценку, не отвлекаясь на лишние сценарии.

### 5.1. Основной третий релиз

**Новые колонки на листе «Расчеты» (после «Розничная цена ЗЯ»):**
- **Наценка сейчас** — текущая наценка от закупочной цены;  
- **Новая Розничная цена ЗЯ** — поле ручного ввода (опционально);  
- **Наценка новая** — наценка от введённой новой цены.

Формула наценки сохранена как в модуле:  
`(Розничная цена − Закупочная цена) / Закупочная цена`.

**Сценарии для пользователя:**
- видимы только **С2: Медиана рынка** и **С4: Произв.цена**;
- сценарии С1 / С3 / С5 сохранены в файле (формулы не ломаются), но скрыты;
- сценарий **С4** автоматически берёт значение из «Новая Розничная цена ЗЯ».

**Анализ рынка:**
- столбец «Откл. от медианы» подсвечивается так же, как «Откл. от средней».

**Streamlit:**
- в шапке указан «Третий релиз»;
- обновлены инструкции и видимые сценарии в UI.

### 5.2. Доработки после третьего релиза (включая Релиз 3.5)

После основного третьего релиза выполнен цикл уточнений по обратной связи:

- исправлена подтяжка **продаж** на лист «Расчеты» по штрихкоду (`VLOOKUP`);
- цветовое выделение колонок наценки (жёлтый / зелёный);
- светофор для сигнала маржи и риска потери ВП;
- автозаполнение рейтинга цены и позиции на рынке;
- на Dashboard — ТОП-10 выше/ниже рынка не только по средней, но и по медиане;
- уточнён расчёт суммарного прогноза валовой прибыли в сценарном анализе;
- веб-приложение синхронизировано с Excel (метка «Релиз 3.5», те же ТОП и расшифровка критического риска).

### Результат для бизнеса

Появился понятный рабочий контур:
1) увидеть текущую наценку;  
2) вручную задать новую розничную цену;  
3) сразу увидеть новую наценку;  
4) оценить решение через сценарий С2 (рынок) и С4 (своя цена).

Лишняя сложность убрана с экрана, при этом расширенные сценарии остались «под капотом» на случай дальнейших доработок.

## 7. Как пользоваться сейчас (кратко)

1. Открыть веб-приложение Streamlit.  
2. Загрузить прайс-лист (обязательно).  
3. При необходимости загрузить файл продаж (или скачать шаблон).  
4. Получить:
   - BI-дашборд с KPI, графиками и выводами;
   - итоговый Excel с формулами для детальной работы.
5. В Excel на листе «Расчеты»:
   - смотреть **Наценка сейчас**;
   - при необходимости ввести **Новую Розничную цену ЗЯ**;
   - сразу видеть **Наценка новая** и результат в сценарии **С4**;
   - сравнивать с рынком через видимый сценарий **С2**.

## 8. Выводы

Модуль прошёл путь от локального Excel-файла к полноценному рабочему инструменту коммерческого блока:

- **логика эталонного Excel сохранена** и воспроизводится программно;  
- **доступ стал проще** — через браузер, без установки Python у пользователя;  
- **аналитика стала быстрее** — KPI и рекомендации видны сразу после загрузки прайса;  
- **управление ценой стало практичнее** — ручной ввод новой розничной цены и мгновенный пересчёт наценки;  
- **сложность интерфейса снижена** — на виду остаются сценарии, реально нужные в текущем процессе (С2 и С4).

С точки зрения руководства продукт перешёл из статуса «файл с формулами» в статус «управляемый цифровой инструмент ценообразования» с понятной версионностью (Релиз 1 → 2 → 3 / 3.5) и возможностью дальнейшего развития без ломки накопленной логики.
